# tacoBraza

Cinematic restaurant website and launch page for Taco Braza, an Estilo Sinaloa taco brand from El Paso, Texas.

The active GitHub Pages site now lives at the repository root for the custom domain `tacobraza.com`.

The legacy `/taco-braza/` path is retained only as a backwards-compatible redirect to the root site.

All site assets were moved from `taco-braza/assets/` to root `assets/`.
